# 王骁 | Xiao Wang

Bilingual academic website. Hosted with GitHub Pages from the main branch.

## Editing

Edit pages in `zh/` and `en/` together. Shared styles and publication filters are in `assets/`. Public CV PDFs are in `downloads/`. Historical blog articles retain their original directories and URLs; do not replace the root with a full Gridea export.

No build step is required. The `.nojekyll` file enables plain static hosting.
